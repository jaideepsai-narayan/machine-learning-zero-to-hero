# Machine Learning for Beginners — Resources

## Knowledge

- [Visual Channel: _StatQuest with Josh Starmer_](https://statquest.org/)
  Bite-sized, step-by-step visual breakdowns of ML algorithms with zero jargon. Use for: visual intuition for Regression, Classification, and Trees.
- [Visual Math: _3Blue1Brown (Essence of Calculus & Neural Networks)_](https://www.youtube.com/@3blue1brown)
  Stunning geometric animations of derivatives, vectors, matrices, and gradient descent. Use for: visualizing mathematical concepts.
- [Interactive Site: _Seeing Theory (Brown University)_](https://seeing-theory.brown.edu/)
  A visual introduction to probability and statistics using interactive web graphics. Use for: probability foundations.
- [Interactive Journal: _Distill.pub_](https://distill.pub/)
  Clear, dynamic interactive explanations of machine learning concepts. Use for: visual mental models of complex landscapes.
- [Book: _Hands-On Machine Learning_ by Aurélien Géron](https://www.oreilly.com/library/view/hands-on-machine-learning/9781492032632/)
  Practical guide balancing intuitive explanations with Python code. Use for: real-world pipelines.

## Wisdom (Communities)

- [r/learnmachinelearning](https://reddit.com/r/learnmachinelearning)
  Beginner-friendly subreddit dedicated to asking questions, sharing project ideas, and debugging concepts.
- [Kaggle Discussions](https://www.kaggle.com/discussion)
  Practical community of learners and practitioners working on real-world datasets.
