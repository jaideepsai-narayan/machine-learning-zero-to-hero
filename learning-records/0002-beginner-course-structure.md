# LR-0002: Machine Learning for Absolute Beginners (Visual & Micro-chunked)

Structured a beginner-friendly "Zero-to-Hero" curriculum designed for learners with no prior AI/ML background. The course relies on real-world visual analogies (Pizza pricing mystery), interactive SVG widgets, color-coded equations ($y = mx + b$, MSE Loss, Gradient Descent update rule), and micro-chunked lessons (5-10 mins each).

## Curriculum Progress
- **Lesson 0002**: What is Machine Learning? (Traditional Code vs ML, $y = mx + b$ pizza interactive slider).
- **Lesson 0003**: How AI Measures Mistakes (Residuals, MSE Loss, interactive residual error line plot).
- **Lesson 0004**: Skiing Down Loss Mountain (Gradient Descent intuition, learning rate $\alpha$, live downhill ball simulation).

## Implications
- Establishes intuitive mental models for optimization before introducing dense multi-layer neural network vector calculus.
