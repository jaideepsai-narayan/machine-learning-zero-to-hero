📊 Master Algorithm Comparison Matrix

Quick side-by-side reference of mathematical objectives, complexities, and primary hyperparameters across all 19 topics:

Module / Algorithm Paradigm Core Mathematical Objective Time Complexity Key Hyperparameters Primary Use Case & Strength
01. Linear Regression Supervised $\min_{w,b} \frac{1}{N}\sum (y_i - (w^T x_i + b))^2$ Train: $O(P^3 + P^2 N)$
Infer: $O(P)$		 Fit intercept, Regularization $\lambda$ Continuous numerical prediction with linear features. Extremely fast & interpretable.
02. Gradient Descent Optimization $w^{(t+1)} = w^{(t)} - \alpha \nabla_w L(w)$ Per step: $O(B \cdot P)$ Learning rate $\alpha$, Batch size $B$, Momentum $\beta$ Universal optimizer for non-closed-form convex and non-convex loss functions.
03. Logistic Regression Supervised $\min -\frac{1}{N}\sum [y \log \hat{p} + (1-y)\log(1-\hat{p})]$ Train: $O(N \cdot P)$
Infer: $O(P)$		 Regularization $C$ (L1/L2), Solver type Binary probability estimation. Baseline for classification & risk scoring.
04. Support Vector Machines Supervised $\min \frac{1}{2}\|w\|^2 + C \sum \xi_i$ Train: $O(N^2 \cdot P)$ to $O(N^3)$
Infer: $O(N_{sv} \cdot P)$		 Penalty $C$, Kernel ($\text{RBF}, \text{Poly}$), Gamma $\gamma$ High-dimensional sparse text & bio-data. Finds maximum margin boundary.
05. Decision Trees Supervised $\max \text{Gain} = \text{Impurity}_{\text{parent}} - \sum \frac{N_j}{N}\text{Impurity}_j$ Train: $O(P \cdot N \log N)$
Infer: $O(\text{depth})$		 max_depth, min_samples_split, Gini/Entropy Non-linear tabular data. Requires zero scaling, automatically handles feature interactions.
06. Random Forests (Bagging) Ensemble $\hat{y} = \frac{1}{B}\sum_{b=1}^{B} T_b(x)$ (Bootstrapped rows + $\sqrt{P}$) Train: $O(B \cdot P \cdot N \log N)$
Infer: $O(B \cdot \text{depth})$		 n_estimators, max_features ($\sqrt{P}$) Reduces high variance of single trees. Strong default tabular performance out of the box.
07. Boosting (XGBoost/AdaBoost) Ensemble $F_m(x) = F_{m-1}(x) + \eta \cdot h_m(x)$ (Residual fitting) Train: $O(M \cdot P \cdot N \log N)$
Infer: $O(M \cdot \text{depth})$		 Learning rate $\eta$, n_estimators, Subsample ratio State-of-the-art benchmark winner on tabular competition datasets.
08. Dimensionality Reduction (PCA) Unsupervised $\max_{\mathbf{v}} \mathbf{v}^T \Sigma \mathbf{v} \quad \text{s.t. } \|\mathbf{v}\|=1$ Train: $O(P^3 + P^2 N)$
Infer: $O(P \cdot k)$		 Number of components $k$, Explained variance ratio Linear feature compression, noise reduction, 2D/3D visualization of dense data.
09. Unsupervised Clustering Unsupervised K-Means: $\min \sum_{k=1}^K \sum_{x \in C_k} \|x - \mu_k\|^2$ K-Means: $O(I \cdot K \cdot N \cdot P)$
DBSCAN: $O(N \log N)$		 K-Means $K$; DBSCAN radius $\epsilon$, min_samples Customer segmentation, anomaly detection, discovering hidden natural patterns.
10. Backpropagation & MLPs Deep Learning $\delta^{[l]} = \left((W^{[l+1]})^T \delta^{[l+1]}\right) \odot \sigma'(z^{[l]})$ Per epoch: $O(N \cdot \sum L_l L_{l-1})$ Architecture, Activation (ReLU/Sigmoid), Learning rate Universal function approximation for complex non-linear multi-layer representations.
11. Convolutional Neural Networks Deep Learning $O = \left\lfloor \frac{W - F + 2P}{S} \right\rfloor + 1$ Forward: $O(N \cdot C_{in} \cdot C_{out} \cdot K_h K_w \cdot H O)$ Kernel size $F$, Stride $S$, Padding $P$, Channels Computer vision & grid data. Spatial weight sharing and shift invariance.
12. Object Detection (YOLO) Deep Learning Loss $= L_{\text{box}} + L_{\text{cls}} + L_{\text{obj}}$ with $\text{IoU}=\frac{|A \cap B|}{|A \cup B|}$ Single pass grid cell inference Anchor box scales, IoU threshold, NMS confidence Real-time bounding box localization and multi-object classification in images/video.
13. Image Segmentation (U-Net) Deep Learning $\text{Dice Loss} = 1 - \frac{2|A \cap B|}{|A| + |B|}$ Encoder-Decoder skip connection pass Skip connections, Bottleneck channels, Loss weights Pixel-level mask classification (medical imaging, autonomous driving road maps).
14. Evaluation & Regularization Evaluation L1 Lasso: $+\lambda \|w\|_1$; L2 Ridge: $+\lambda \|w\|_2^2$ Evaluation: $O(N)$ Penalty $\lambda$, Dropout rate $p$, CV folds $k$ Preventing overfitting/underfitting, feature selection, and un-biased metric scoring.
15. Text Embeddings & NLP NLP $\text{TF-IDF} = \text{TF} \times \log\left(\frac{|D|}{|\{d: t \in d\}|}\right)$ Embedding lookup: $O(1)$ Vector dimension $d$, Window size, Min count Converting unstructured text into semantic dense vector space representations.
16. Sequence Models (LSTM/GRU) Deep Learning $h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b)$ Per sequence: $O(T \cdot d^2)$ Hidden size $d$, Num layers, Dropout Processing sequential data (time-series, audio, text) with gated memory cells.
17. Transformers & Attention Deep Learning $\text{Attention}(Q, K, V) = \text{Softmax}\left( \frac{Q K^T}{\sqrt{d_k}} \right) V$ Per layer: $O(T^2 \cdot d)$ Number of heads $h$, Model dim $d_{model}$, Context $T$ Parallel self-attention over long-range dependencies powering modern LLMs & Foundation models.
18. Generative AI (GANs/Diffusion) Generative AI $\min_G \max_D V(D,G)$ / $L_{\text{simple}} = \mathbb{E}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$ Diffusion: $T$ reverse denoising steps Timesteps $T$, Noise schedule $\beta_t$, Guidance $w$ Creating ultra-realistic synthetic images, text-to-image art, and data generation.

🚀 The Complete 19-Lesson Evolutionary Timeline

1. Linear Regression [Lesson 0002]

Goal & Formula: Fit a continuous line $y = w \cdot x + b$ minimizing Mean Squared Error (MSE): $\frac{1}{N}\sum (y_i - \hat{y}_i)^2$.

⚠️ Major Drawback: Outputs unbounded continuous numbers ($-\infty, +\infty$). It cannot handle binary (Yes/No) classification or estimate bounded probabilities.
💡 Why Move to Next Algorithm? We need a mathematical squishing function to map predictions between $0.0$ and $1.0$ $\implies$ Logistic Regression.

2. Optimization: Gradient Descent & Adam [Lesson 0003]

Goal & Formula: Iteratively update weights opposite the gradient: $w \leftarrow w - \alpha \nabla_w L$. Closed-form inversion $(X^T X)^{-1}$ costs $O(P^3)$ and fails on huge data!

⚠️ Major Drawback: Vanilla batch gradient descent is slow on massive datasets and gets stuck in local minima or saddle points.
💡 Why Move to Next Algorithm? Use mini-batch sampling and adaptive momentum (Adam) to speed up training across non-convex loss surfaces.

3. Logistic Regression [Lesson 0004]

Goal & Formula: Pass linear outputs through the Sigmoid S-curve: $\hat{p} = \frac{1}{1 + e^{-(w^T x + b)}}$, minimizing Binary Cross-Entropy Log Loss.

⚠️ Major Drawback: Can only draw a linear (flat) decision boundary. Completely fails on non-linearly separable data (e.g., XOR patterns) without manual feature engineering.
💡 Why Move to Next Algorithm? We need max-margin boundaries and kernel transformations $\implies$ SVMs, or automated decision trees $\implies$ Decision Trees.

4. Support Vector Machines (SVMs) [Lesson 0005]

Goal & Formula: Maximize street margin $\frac{2}{\|w\|}$ with Soft Margin Penalty $C$ and RBF Kernel $K(x, x') = \exp(-\gamma \|x - x'\|^2)$.

⚠️ Major Drawback: Training complexity is $O(N^2)$ to $O(N^3)$. Computationally unfeasible for datasets exceeding hundreds of thousands of samples.
💡 Why Move to Next Algorithm? We need intuitive, non-parametric split models that scale better on large tabular datasets $\implies$ Decision Trees.

5. Decision Trees [Lesson 0006]

Goal & Formula: Recursively split data using feature threshold questions maximizing Information Gain (minimizing Gini Impurity $G = 1 - \sum p_i^2$).

⚠️ Major Drawback: High Variance & Overfitting! A deep decision tree memorizes noise in training data, resulting in poor generalization on test data.
💡 Why Move to Next Algorithm? Reduce high variance by averaging hundreds of independent trees trained on random row/feature subsets $\implies$ Bagging & Random Forests.

6. Bagging & Random Forests [Lesson 0007]

Goal & Formula: Train $B$ independent decision trees in parallel using bootstrapped samples and random feature subsets ($\sqrt{P}$). Aggregate via majority vote.

⚠️ Major Drawback: Trees are built independently in parallel, so hard-to-predict samples get ignored if the majority vote gets them wrong.
💡 Why Move to Next Algorithm? Build trees sequentially, where each new tree specifically fits the residual errors of prior trees $\implies$ Boosting (XGBoost).

7. Boosting (AdaBoost, Gradient Boosting & XGBoost) [Lesson 0008]

Goal & Formula: Fit sequential tree ensembles on negative loss gradients: $F_m(x) = F_{m-1}(x) + \eta \cdot h_m(x)$.

🏆 Tabular Dominance: Achieves state-of-the-art competition benchmarks on tabular datasets! But what about unlabelled data or high-dimensional compression?

8. Dimensionality Reduction (PCA, t-SNE, UMAP) [Lesson 0009]

Goal & Formula: Project high-dimensional features onto lower orthogonal axes maximizing variance: $\text{Ratio} = \frac{\sum_{i=1}^k \lambda_i}{\sum_{j=1}^P \lambda_j}$.

⚠️ Major Drawback: Linear PCA cannot unroll non-linear manifolds (e.g. Swiss-roll). t-SNE/UMAP fix non-linear projections but cannot predict on new unseen test points easily.
💡 Why Move to Next Algorithm? We need algorithms that group data without predefined coordinates or target labels $\implies$ Unsupervised Clustering.

9. Unsupervised Clustering (K-Means, Hierarchical & DBSCAN) [Lesson 0010]

Goal & Formula: Group unlabelled data by distance or density. Silhouette score $s(i) = \frac{b(i)-a(i)}{\max(a(i),b(i))}$.

⚠️ Major Drawback: K-Means requires pre-specifying $K$ and assumes spherical clusters. DBSCAN struggles with varying density clusters.
💡 Why Move to Next Algorithm? We need hierarchical feature representation learning for unstructured perceptual inputs (images, audio) $\implies$ Neural Networks.

10. Neural Networks & Backpropagation [Lesson 0011]

Goal & Formula: Train multi-layer perceptrons via chain rule calculus: $\delta^{[l]} = \left((W^{[l+1]})^T \delta^{[l+1]}\right) \odot \sigma'(z^{[l]})$.

⚠️ Major Drawback: Flattening 2D/3D images into 1D vectors destroys spatial structure and leads to parameter explosion (millions of weights for small images).
💡 Why Move to Next Algorithm? Preserved 2D spatial locality with small sliding filter kernels and weight sharing $\implies$ Convolutional Neural Networks (CNNs).

11. Convolutional Neural Networks (CNNs) [Lesson 0012]

Goal & Formula: Apply spatial sliding filters $(I * K)$ with dimension $O = \left\lfloor \frac{W - F + 2P}{S} \right\rfloor + 1$ and ResNet skip connections $y = F(x) + x$.

⚠️ Major Drawback: Standard classification CNNs only output a single global label per image, ignoring where objects are located.
💡 Why Move to Next Algorithm? We need localization bounding boxes and multi-object spatial coordinates $\implies$ Object Detection (YOLO).

12. Object Detection (YOLO & Faster R-CNN) [Lesson 0013]

Goal & Formula: Predict bounding boxes $(x,y,w,h)$ and class probabilities simultaneously, evaluated via Intersection over Union $\text{IoU} = \frac{|A \cap B|}{|A \cup B|}$.

⚠️ Major Drawback: Bounding boxes are rectangular boxes. They cannot identify exact pixel boundaries or organic shapes (e.g., tumor boundaries, road surfaces).
💡 Why Move to Next Algorithm? We need pixel-level mask classification $\implies$ Image Segmentation (U-Net).

13. Image Segmentation (U-Net & Mask R-CNN) [Lesson 0014]

Goal & Formula: Encoder-decoder contracting/expanding path with skip connections, evaluated via Dice Loss $= 1 - \frac{2|A \cap B|}{|A| + |B|}$.

🏆 Vision Milestone: Provides full per-pixel semantic and instance segmentation maps for medical and robotic vision.

14. Model Evaluation & Regularization [Lesson 0015]

Goal & Formula: Prevent overfitting via L1 Lasso ($\lambda |w|$), L2 Ridge ($\lambda \|w\|^2$), Dropout, and cross-validation metrics ($F_1, \text{ROC-AUC}$).

📐 Universal Rule: Essential validation methodology for all machine learning and deep learning pipelines.

15. Text Embeddings & NLP (TF-IDF & Word2Vec) [Lesson 0016]

Goal & Formula: Map raw text into dense semantic vector spaces where vector distance reflects meaning: $\text{CosSim}(A,B) = \frac{A \cdot B}{\|A\| \|B\|}$.

⚠️ Major Drawback: Word2Vec produces static embeddings (e.g. "Apple" phone vs "Apple" fruit share the exact same single vector).
💡 Why Move to Next Algorithm? We need dynamic sequential state context across time $\implies$ Sequence Models (LSTMs).

16. Sequence Models (RNNs, LSTMs & GRUs) [Lesson 0017]

Goal & Formula: Maintain recurrent hidden states $h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t)$ with gated memory cells (Forget, Input, Output gates) to prevent vanishing gradients.

⚠️ Major Drawback: Sequential computation ($t-1 \to t$) prevents GPU parallelization during training, creating a bottleneck on long text sequences.
💡 Why Move to Next Algorithm? Process all sequence tokens simultaneously in parallel using self-attention matrix multiplication $\implies$ Transformers.

17. Transformers & Self-Attention [Lesson 0018]

Goal & Formula: Scaled Dot-Product Self-Attention: $\text{Attention}(Q, K, V) = \text{Softmax}\left( \frac{Q K^T}{\sqrt{d_k}} \right) V$.

🚀 Modern Foundation AI: Eliminates sequential recurrence, enabling massive parallel pre-training for modern Large Language Models (LLMs)!

18. Generative AI (GANs, VAEs & Diffusion Models) [Lesson 0019]

Goal & Formula: Generate new synthetic data using Adversarial Minimax $\min_G \max_D V(D,G)$ or Latent Diffusion Noise Denoising $L_{\text{simple}} = \mathbb{E}\left[\|\epsilon - \epsilon_\theta(x_t, t)\|^2\right]$.

🎨 The Frontier: Powers state-of-the-art text-to-image generation, synthetic voice, video synthesis, and creative AI.
