Backpropagation Reference Cheat Sheet

Topic: Machine Learning Foundations Type: Quick Reference ← Back to Lesson 0001

1. Core Forward & Backward Equations

For layer \(l \in \{1, \dots, L\}\):

Forward Pass
\[ z^{[l]} = W^{[l]} a^{[l-1]} + b^{[l]} \] \[ a^{[l]} = \sigma(z^{[l]}) \] where \(a^{[0]} = x\) (input vector).
Backward Pass Error Vector \(\delta^{[l]}\)
\[ \delta^{[L]} = \nabla_{a^{[L]}} L \odot \sigma'(z^{[L]}) \] \[ \delta^{[l]} = \left( (W^{[l+1]})^T \delta^{[l+1]} \right) \odot \sigma'(z^{[l]}) \]
Weight & Bias Parameter Gradients
\[ \frac{\partial L}{\partial W^{[l]}} = \delta^{[l]} (a^{[l-1]})^T \] \[ \frac{\partial L}{\partial b^{[l]}} = \delta^{[l]} \]

2. Matrix Calculus & Dimension Rules

Symbol Description Shape / Dimensions
\(a^{[l-1]}\) Activation vector of layer \(l-1\) \((n_{l-1} \times 1)\)
\(W^{[l]}\) Weight matrix for layer \(l\) \((n_l \times n_{l-1})\)
\(b^{[l]}\) Bias vector for layer \(l\) \((n_l \times 1)\)
\(z^{[l]}\) Pre-activation linear combination \((n_l \times 1)\)
\(\delta^{[l]}\) Error vector \(\frac{\partial L}{\partial z^{[l]}}\) \((n_l \times 1)\)
\(\frac{\partial L}{\partial W^{[l]}}\) Gradient matrix w.r.t weights \((n_l \times n_{l-1})\) (Same shape as \(W^{[l]}\))

3. Complexity Comparison

  • Forward Finite Differences: \(O(|W| \cdot \text{Forward Cost})\) — requires \(2|W|\) forward passes to evaluate numerical gradients perturbing one weight at a time.
  • Forward-Mode Automatic Differentiation: Computes \(\frac{\partial a^{[L]}}{\partial w_i}\) forward alongside function values. Requires 1 pass per input feature or parameter (\(O(|W|)\) passes for scalar loss).
  • Reverse-Mode Automatic Differentiation (Backpropagation): Computes \(\frac{\partial L}{\partial w_i}\) for ALL parameters simultaneously in ONE forward pass and ONE backward pass. Time complexity is \(O(|W|)\) — roughly \(2 \times\) the cost of a single forward pass.
