Sequential Models: RNNs & LSTMs ⌛

Level: Advanced Topic: Time-Series, Recurrent Loops, Vanishing Gradients & LSTM Memory Gates ← Lesson 0016

1. WHY Do Feedforward Networks Fail on Sequential Data? (Drawbacks of Input Independence)

Standard feedforward networks assume all inputs $x$ are completely independent. But for text ("The movie was not...") or time-series stock prices, order matters!

Recurrent Neural Networks (RNNs) introduce a loop that passes a hidden memory state vector $h_{t-1}$ from step to step.

🌍 Real-World Industry Context & Case Studies

Recurrent architectures specialize in sequential time-series and audio signal processing:

  • 📈 Financial Time-Series Forecasting: Predicting stock price volatility and algorithmic trading signals based on sequential minute-by-minute order book data.
  • 🌤️ Weather & Energy Load Forecasting: Meteorological models tracking historical hourly temperature, humidity, and barometric pressure patterns.
  • 🏥 ICU Patient Health Monitoring: Tracking patient heart rate and oxygen saturation streams to predict cardiac arrest hours before symptoms appear.

2. WHAT IS IT? (Recurrent Memory Loops & LSTM Gated Highways)

\[ h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h) \]
⚠️ The Vanishing Gradient Failure Mode: During Backpropagation Through Time (BPTT), gradients are multiplied by $W_{hh}$ over every time step. Over 50 time steps, $(0.9)^{50} → 0$! The network completely forgets early words in a sentence!

3. HOW Does It Work? (Forget $f_t$, Input $i_t$, Output $o_t$ Gates & Cell State $c_t$ Update)

LSTMs solve vanishing gradients by adding an uninterrupted Cell State Memory Highway ($c_t$) controlled by 3 mathematical gates:

The 3 LSTM Gates
  • Forget Gate ($f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$): Decides what details to erase from memory.
  • Input Gate ($i_t = \sigma(W_i [h_{t-1}, x_t] + b_i)$): Decides what new information to write into memory.
  • Output Gate ($o_t = \sigma(W_o [h_{t-1}, x_t] + b_o)$): Decides what part of memory to output as $h_t$.

Updated Cell State: $c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$.

⌛ Vanishing Gradients in BPTT & The Cell State Error Highway
  • Vanishing Gradients in BPTT: When backpropagating gradients back 50 time steps through vanilla RNNs, repeatedly multiplying weight matrix $W_{hh}$ shrinks gradients exponentially ($0.9^{50} \approx 0.005$). The network completely forgets early inputs!
  • Cell State ($c_t$) as the Constant Error Highway: LSTMs solve this by introducing an additive cell state highway:
    • \[ c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t \] Because operations are additive rather than purely multiplicative, gradients flow unchanged back through hundreds of time steps!
  • Bidirectional LSTMs (BiLSTM): Runs two separate hidden layers—one reading sequence forward ($1 \to T$) and one reading backward ($T \to 1$). Merging both hidden states provides complete past and future context!

⚡ Practical Decision Guide: Sequential Architectures

Architecture Gate Complexity Max Sequence Memory Parallel Compute When to Use
Vanilla RNN None (Single $W_{hh}$) Very Short (< 10 steps) Sequential ($O(T)$) Toy sequential problems only (Obsolete in production)
LSTM 3 Gates (Forget, Input, Output) Long (100-500 steps) Sequential ($O(T)$) Time-series sensor forecasting, financial order books, lightweight audio
GRU (Gated Recurrent Unit) 2 Gates (Reset, Update) Long (100-500 steps) Sequential ($O(T)$) Faster training alternative to LSTM with slightly fewer parameters
Transformer Self-Attention ($Q, K, V$) Massive (128,000+ tokens) Fully Parallel ($O(1)$) Large Language Models, Machine Translation, modern NLP
