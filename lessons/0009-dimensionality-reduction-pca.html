Dimensionality Reduction: PCA & t-SNE 📉

Level: Intermediate Topic: The Curse of Dimensionality, PCA Eigenvectors & Manifold Learning ← Lesson 0008

1. WHY Do We Need Dimensionality Reduction? (Drawbacks of High Dimensions & Sparsity)

Imagine trying to locate a friend in a 1D line vs a 2D room vs a 3D building vs a 1,000-dimensional space! In 1,000 dimensions, data points become infinitely far apart, and models overfit severely.

Dimensionality Reduction squishes thousands of noisy features down to 2 or 3 principal axes while keeping the core information!

🌍 Real-World Industry Context & Case Studies

Dimensionality Reduction turns untrackable high-dimensional data into actionable insights:

  • 🖼️ Image & Signal Compression (Eigenfaces): Facial recognition systems reduce high-resolution $1024 \times 1024$ pixel images to just 50 principal components while keeping key facial structures.
  • 🧬 Genomic Single-Cell RNA Sequencing: Geneticists reduce 20,000 gene expressions per cell into 2D plots to visualize cell cell-type clusters.
  • ⚡ Preprocessing for ML Models: Removing collinear, redundant features before feeding data into linear models to prevent multi-collinearity.

2. WHAT IS IT? (Principal Component Analysis & Manifold Embeddings)

PCA finds new orthogonal axes (Principal Components) that maximize variance:

  1. Standardize Data: Zero-center features ($\mu = 0, \sigma = 1$).
  2. Compute Covariance Matrix $\Sigma$: \[ \Sigma = \frac{1}{N} X^T X \]
  3. Calculate Eigenvectors & Eigenvalues: \[ \Sigma v_i = \lambda_i v_i \] The eigenvector $v_1$ with the largest eigenvalue $\lambda_1$ is Principal Component 1 ($PC_1$)!
  4. Project Data: $X_{\text{new}} = X \cdot W_k$ where $W_k$ contains top $k$ eigenvectors.
Explained Variance Ratio
\[ \text{Variance Ratio} = \frac{\lambda_1 + \lambda_2}{\sum \lambda_i} \]

3. HOW Does It Work? (Covariance Matrix $\Sigma$, Eigenvectors, and Eigenvalues)

PCA only draws straight linear axis projections. If data lies on a curved manifold (like a Swiss Roll), PCA squishes distinct clusters together!

t-SNE & UMAP Concept
t-SNE and UMAP preserve local neighbor distances using Student-t probability distributions, allowing complex clusters to unpack cleanly in 2D visual maps.
⚠️ Feature Scaling Requirement & Explained Variance
  • Mandatory Feature Standardization (Z-Score): PCA looks for axes of maximum variance. If feature $x_1$ is measured in dollars ($0 \text{ to } 1,000,000$) and feature $x_2$ in meters ($0 \text{ to } 2$), PCA will completely ignore feature $x_2$. You MUST scale features to $\mu=0, \sigma=1$ before running PCA.
  • Explained Variance Ratio: Each eigenvector $\mathbf{v}_i$ has an eigenvalue $\lambda_i$ measuring variance along that axis. The fraction of total information preserved by $k$ components is:
    • \[ \text{Explained Variance Ratio} = \frac{\sum_{i=1}^{k} \lambda_i}{\sum_{j=1}^{P} \lambda_j} \] Targeting $95\%$ cumulative explained variance is standard practice.
  • Linear PCA vs. Non-Linear Embeddings (t-SNE / UMAP): PCA only finds straight linear projection axes. For non-linear Swiss-roll manifold data, modern AI uses t-SNE or UMAP to preserve local cluster topology.

⚡ Practical Decision Guide: PCA vs. t-SNE vs. UMAP

Algorithm Projection Type Preserves Global vs. Local Computational Speed When to Use
PCA Linear Hyperplane Projection Global Structure & Distances Ultra-Fast ((P^3)$ matrix math) Feature reduction before model training & noise removal
t-SNE Non-Linear Manifold (Probability distribution) Local Cluster Topology Slow ((N^2)$) High-quality 2D/3D visual cluster exploration
UMAP Non-Linear Riemannian Geometry Both Local & Global Structure Fast ((N \log N)$) Modern single-cell genomics & general embedding visualization
