Sorting Things: Logistic Regression 🐱 vs 🐶

Level: Beginner Topic: Classification, Sigmoid Function & Log Loss ← Lesson 0003

1. WHY Do We Need Logistic Regression? (Drawbacks of Linear Regression on Yes/No Choices)

In Linear Regression, we predicted continuous numbers like pizza prices ($15.50). But what if we want to answer a Yes/No question?

  • Is this email Spam (1) or Not Spam (0)?
  • Will a patient have heart disease Yes (1) or No (0)?

If we use a straight line $y = mx + b$, predictions can shoot off to $+\infty$ or $-\infty$. We need a magic mathematical function that squishes any number between 0 and 1 (a Probability!).

🌍 Real-World Industry Context & Case Studies

Logistic Regression is the workhorse classification algorithm across mission-critical industries:

  • 🏥 Medical Screening: Predicting whether a tumor biopsy is Malignant (1) vs. Benign (0).
  • 💳 Credit Default Prediction: Banks estimate the probability ($0.0$ to $1.0$) that an applicant will default on a credit loan.
  • 📧 Gmail Spam Filter: Classifying incoming emails as Spam (1) or Inbox (0) in real time.

2. WHAT IS IT? (Mapping Scores to Probabilities via the Sigmoid S-Curve)

The Sigmoid Function takes any real number $z$ and bends it into an S-shaped curve between $0$ and $1$:

The Sigmoid Formula
\[ \sigma(z) = \frac{1}{1 + e^{-z}} \] where $z = m \cdot x + b$.

Step-by-Step Derivation of Predictions:

  1. Compute linear score: $z = m \cdot x + b$.
  2. Pass through Sigmoid: $\hat{p} = \sigma(z) = \frac{1}{1 + e^{-z}}$.
  3. If $\hat{p} \ge 0.5 \implies$ Predict Class 1 (Yes). Otherwise Predict Class 0 (No).

3. HOW Does It Work? (Sigmoid Formula $\sigma(z)$ & Log Loss Derivation)

Mean Squared Error works poorly for probabilities. Instead, we use Log Loss, which severely punishes an AI that is confidently WRONG!

Binary Cross-Entropy Loss
\[ \text{Loss} = - \Big[ y \log(\hat{p}) + (1 - y) \log(1 - \hat{p}) \Big] \]
  • If true label $y = 1$: Loss $= -\log(\hat{p})$. If $\hat{p} → 0$, Loss $→ +\infty$ (Huge Penalty!).
  • If true label $y = 0$: Loss $= -\log(1 - \hat{p})$. If $\hat{p} → 1$, Loss $→ +\infty$ (Huge Penalty!).
🔥 Binary Cross-Entropy Loss (Log Loss)

We cannot use MSE for Logistic Regression because Sigmoid turns the loss curve non-convex with many local trap valleys! Instead, we use Log Loss:

\[ \mathcal{L}(\theta) = - \frac{1}{N} \sum_{i=1}^{N} \left[ y_i \log(\hat{y}_i) + (1 - y_i) \log(1 - \hat{y}_i) \right] \]
  • If true label $y = 1$ and prediction $\hat{y} \to 0$, Loss explodes to $+\infty
  • If true label $y = 0$ and prediction $\hat{y} \to 1$, Loss explodes to $+\infty
🎛️ Tuning Decision Thresholds & Multi-Class Softmax
  • Threshold Tuning: By default, threshold is 0.5$. In medical diagnosis, we lower the threshold to 0.15$ to catch every possible cancer case (maximizing Recall), accepting a few false alarms.
  • Multi-Class (Softmax): For $K > 2$ classes (e.g. Cat vs. Dog vs. Bird), Sigmoid generalizes to Softmax:
\[ \text{Softmax}(z)_i = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}} \]

⚡ Practical Decision Guide: Linear vs. Binary vs. Multi-Class

Model Target Output Activation Loss Function When to Use
Linear Regression Continuous number ($y \in \mathbb{R}$) None (Identity) MSE / MAE Predicting house prices, temperature, sales revenue
Logistic Regression Probability $P(y=1) \in [0, 1]$ Sigmoid $\sigma(z)$ Binary Cross-Entropy Binary Yes/No classification (Spam, Fraud, Disease)
Softmax Regression Multi-class probability distribution Softmax Categorical Cross-Entropy Multi-class classification (Handwritten digits 0-9, Image categories)
