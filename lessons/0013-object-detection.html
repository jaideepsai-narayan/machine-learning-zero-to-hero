Object Detection: Finding WHERE Things Are 📦

Level: Advanced Topic: Bounding Boxes (x,y,w,h), IoU, R-CNN, YOLO & NMS ← Lesson 0012

1. WHY Is Classification Not Enough? (Drawbacks of Single-Label Predictions)

Image Classification tells you "What" is in an image. But for autonomous driving or robotics, you need to know "Where" every object is!

Object Detection predicts both a Class Label AND a 4-coordinate Bounding Box: $[x_{\text{center}}, y_{\text{center}}, \text{width}, \text{height}]$.

🌍 Real-World Industry Context & Case Studies

Object Detection answers "WHAT and WHERE" for real-time robotic systems:

  • 🚗 Self-Driving Vehicles (Tesla / Waymo): Detecting cars, pedestrians, stop signs, and cyclists at 60 FPS to calculate collision trajectories.
  • 🛒 Cashierless Retail (Amazon Go): Tracking items grabbed off store shelves using ceiling camera object detectors.
  • 🚁 Aerial Drone Inspection: Scanning solar panel farms or agricultural fields to detect damaged equipment and crop pests.

2. WHAT IS IT? (Predicting Bounding Boxes $[x,y,w,h]$ and Real-Time YOLO)

How do we evaluate if a predicted bounding box matches the ground-truth box?

Intersection over Union (IoU) Formula
\[ \text{IoU} = \frac{\text{Area of Overlap}(B_{\text{pred}} \cap B_{\text{gt}})}{\text{Area of Union}(B_{\text{pred}} \cup B_{\text{gt}})} \]
  • $\text{IoU} = 1.0$: Perfect overlap match!
  • $\text{IoU} \ge 0.5$: Standard benchmark threshold for a correct detection.

3. HOW Does It Work? (Intersection over Union (IoU) & Non-Maximum Suppression (NMS))

⚠️ Two-Stage Detectors (R-CNN, Faster R-CNN): Propose 2,000 candidate boxes first, then classify each box. Very accurate, but far too slow for real-time video!
💡 One-Stage Revolution: YOLO (You Only Look Once)
YOLO treats object detection as a single regression problem! It divides the image into an $S \times S$ grid. A single forward neural network pass predicts all bounding boxes and class probabilities simultaneously in real time (60+ FPS)!

4. Cleaning Duplicate Predictions: Non-Maximum Suppression (NMS)

  1. Filter out all bounding boxes with confidence score below threshold (e.g. $< 0.5$).
  2. Pick the box with the highest confidence score.
  3. Eliminate any remaining boxes that have $\text{IoU} > 0.5$ with that top box (remove duplicate overlaps!).
🎯 Evaluation Metric: mAP & One-Stage vs. Two-Stage Detectors
  • One-Stage (YOLO / SSD) vs. Two-Stage (Faster R-CNN):
    • One-Stage (YOLO): Predicts bounding boxes and class probabilities in a single forward pass. Ultra-fast (30-150 FPS), ideal for real-time edge hardware.
    • Two-Stage (Faster R-CNN): First proposes region candidates (RPN), then classifies each region. Higher accuracy on small objects, but slower (5-15 FPS).
  • Mean Average Precision (mAP): The standard industry metric for object detection. Calculates the area under the Precision-Recall curve across all classes:
    • mAP@0.50: Evaluates predictions at a lenient IoU threshold of 0.50.
    • mAP@0.50:0.95 (COCO metric): Averages mAP across IoU thresholds from 0.50 to 0.95 in 0.05 steps.
  • Anchor Boxes & Feature Pyramid Networks (FPN): Pre-defined bounding box aspect ratios that allow detectors to identify tiny objects (birds) and huge objects (trucks) simultaneously.
